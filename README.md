# To Do List · Windows 悬浮待办

基于已确认视觉稿开发的第一版真实桌面应用。Electron + React + TypeScript，使用 Electron 内置 Node.js 的 SQLite；用户不需要安装 Node.js、Python 或 SQLite。

## 下载与运行（推荐安装版）

推荐安装版 `release/installer/To-Do-List-Setup-0.5.1-x64.exe`：双击安装，自动创建开始菜单与桌面快捷方式；安装版内置自动更新，之后的新版本会在应用内自动下载并提示安装。0.4.x 及更早的安装版请先卸载旧版再安装本版（应用标识已更新，直接安装会留下旧的卸载入口；事项数据保存在 `%APPDATA%/To-Do-List`，卸载旧版不会清除数据），此后即可自动更新。

免安装版 `release/portable/To-Do-List-0.5.1-Windows-x64-Portable.zip` 作为备选：

1. 将 ZIP 完整解压到任意普通文件夹。
2. 双击其中的 `To Do List.exe`。
3. 整个解压目录必须一起保留，不能只复制 exe，也不要直接在压缩包预览窗口中运行。

升级免安装版时，先从托盘右键退出旧版本，再解压新版并替换整个程序目录。事项数据独立保存在 `%APPDATA%/To-Do-List`，更换程序目录不会清空事项；仍建议升级前从设置导出一次备份。

本版针对 Windows x64，当前实测 Windows 11；尚未在干净 Windows 10/ARM64 上验证。不提供 macOS 构建。安装包尚未购买代码签名证书，Windows 可能提示发布者未验证。

## 日常使用

- 拖动顶栏移动，图钉切换置顶；可在「设置 → 通用 → 窗口宽度」选择标准440px或窄版340px，选择会自动保存，展开与收起共用该宽度。顶栏独立的「收起为卡片」按钮保持窗口上沿与宽度，用约180ms让底边向上收至176px，完整标题栏始终保留；展开用约240ms向下恢复先前高度。系统开启“减少动态效果”时立即切换。
- 小卡片显示今天及逾期的未完成事项：有具体时间的事项排在前面，同时间按创建顺序排列；右侧只保留「新增事项」和「AI 助手」。顶部在有明确动作时显示一条 AI 建议，点击后在卡片内向下展开。新增事项支持待办/日程、日期与半小时时间、提醒、优先级、标签、进度和备注；选择面板临时向下展开，同一图标再次点击收起。待办可直接完成，点击标题进入完整编辑。
- 窗口显示时任务栏会出现应用图标。右上角“最小化”只隐藏主界面并移除任务栏图标，不影响 AI 对话或提醒；点击托盘的“打开待办”或按 `Ctrl + Shift + Space` 再显示。快捷键被其他软件占用时使用托盘。
- 点“+”填写名称、标签、日期和备注；标题旁可切换待办或日程。待办可设优先级，时间可不填；日程必须填写时间。标签可自定义名称和颜色，删除标签只会把关联事项变为“无标签”。
- 主窗口底部只保留星形 AI 入口，点击打开独立悬浮对话。日期右侧「新增」或窗口内 `Ctrl+N` 打开手动记录并聚焦标题，输入名称按 Enter 即可按默认今天保存；日期与提醒可再调整。「事项库」或 `Ctrl+F` 提供全部日期的搜索、标签筛选、未完成/已完成/已删除、恢复与批量处理。
- 点列表条目编辑，点方框完成；从“全部事项 → 已删除”恢复误删事项。
- 到期事项可“稍后10分钟”。未完成待办跨天保留，不自动篡改原截止时间。
- 设置里可切换标准/窄版窗口宽度、启用登录启动、导出 JSON 备份、打开数据目录。
- 托盘右键“退出（停止提醒）”才结束进程。关机、睡眠和应用退出期间无法发通知；重新启动/唤醒后补查未送达提醒。Windows 勿扰模式或通知权限可能阻止弹出。

## AI 设置和隐私

在设置的 AI 配置页选择常用供应商 → 填写 API Key → 填写模型名称/ID → 测试连接 → 添加并使用。预设为 OpenAI、Anthropic、DeepSeek，地址和协议收在「高级设置」，自定义服务默认展开。支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages、HTTP/HTTPS；远程 HTTP 会明文传输密钥、事项及对话，仅建议可信内网或本机。已有设置自动保存：开关立即保存，文本离开输入框保存；底部显示状态，「完成」会先等待保存。新建项目需明确添加；删除与移除密钥需确认。

例：先说“明天下午产品评审”，AI 可以在独立对话气泡中边生成边显示追问；回复“3点，提前10分钟提醒”后，会给出完整建议。每项变更各是一张可选择、编辑的卡片；待确认时仍可继续追问，AI 返回新方案后旧版本会标记为已更新。只有点击“应用所选”才会写入对应事项，也可以直接放弃。你也可以讨论“把项目报告改到周五下午5点”或“总结今天的工作”。主清单始终可见，气泡箭头在主界面指向右下角 AI 按钮、图标模式下指向圆形图标，窗口可拖动，并可在 320×420 到 620×820 之间缩放。有歧义时模型应继续提问。请自行核对时间和事项对象，模型输出不保证正确。

小卡片的「AI 助手」在卡片内打开，与独立助手共享当前会话和输入草稿。三个快捷指令会随当前事项变化，右下角模型菜单按供应商分组。运行时显示 Pi Agent Loop 的真实当前工具、已完成数量、不定进度和流式回复，不预估总步骤；处理记录只展示真实工具事件。多项变更可滚动阅读，底部固定「放弃建议」和「应用 N 项」，确认前不会写入事项。点「展开 AI 对话」会恢复主界面并打开独立助手，继续同一对话并管理历史或模型。

每次 AI 发送会上传本次输入、当前对话最近6轮、已有标签和最近最多120条事项（每条备注最多1000字）到当前模型服务。助手显示未启用/未配置模型/可用/正在回复/等待确认等状态（可用代表已配置，不等于已验证网络连通）；显示流式回复及可展开的真实工具状态和结果，不显示内部推理，也不把它包装成预先确定次数的“执行轨迹”。当前 Pi 会话禁用 Skills，只开放读取事项、生成待确认的事项新增/修改，以及标签新增/修改/删除工具；没有删除事项工具，界面也不会虚构 Skill 步骤。展开版可在待确认时继续追问或卡内编辑，只有选中的变更会在确认后写入；收缩卡片保持既有单轮确认节奏。历史对话和草稿保存在本机 SQLite，退出后保留；新对话需确认且保留旧会话，可从历史选择。重启后待确认建议失效，须重新生成，避免重复执行。数据库不加密事项或对话正文；API Key 使用 Windows 系统加密，不进入渲染进程或事项备份。JSON 事项备份不包含对话历史。不自动上传、无自有云服务或遥测；模型费用由服务方收取。

## 数据与备份

实际目录以设置中的“打开数据目录”为准，继续使用 `%APPDATA%/To-Do-List` 以兼容旧版本数据。`tasks.db` 包含事项、标签、设置、AI 对话、草稿与可见工具事件；运行中可能还有 `tasks.db-wal` 和 `tasks.db-shm`。迁移完整数据库前先从托盘退出应用，不要运行中只复制单个 db。JSON 导出不含密钥或 AI 对话；本版尚无 JSON 导入入口。卸载默认保留用户数据。

本应用不读取或迁移原始 Skill 的外部日记文件，桌面应用数据与原脚本数据独立。

安装版（NSIS）内置自动更新：启动约半分钟后向 GitHub Releases 检查新版，发现即后台下载，完成后弹出通知，可点击立即重启安装，或等退出应用时自动安装；也可随时从托盘菜单选择"检查更新"。免安装版（Portable）不含自动更新，请手动下载新版解压替换。在首个带更新器的版本发布之前，更早的安装版仍需手动升级一次。

## 面向开发者

构建、测试与版本发布的完整流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

当前没有重复事项、云同步、语音输入或多设备功能。安装版支持检查更新；免安装版手动替换目录。对话历史保存在本机，不提供云端同步。

### 悬浮入口（暂时下线）

当前正式版本不创建悬浮入口窗口，也不在主界面标题栏、设置或托盘中显示相关控制。原窗口实现、图标资产、IPC 与既有用户配置均保留在代码和数据中，后续恢复功能时可继续使用；隐藏主界面仍不会关闭正在进行的 AI 对话。
