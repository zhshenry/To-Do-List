# 折叠卡片任务叠层 · 布局修复与状态徽章

提案日期：2026-09-21 · 目标版本：0.5.6 · 预览：`preview.html` → `capture.mjs` → `mini-task-card-proposal.png`（v2）

## 问题与根因（0.5.5 现状）

1. **标题提前换行**：正面卡是 `22px | 标题列(1fr) | 换页器(auto)` 三列网格。窄卡（340）内容宽约 312px，换页器占约 74px、勾选框与间距约 50px，标题列仅剩约 180px——与常见标题排印宽度正好临界，被迫折行。
2. **标签、换页器越界**：卡片定高 86px，「类型行 + 两行标题 + 标签行」最少约 88px，内容本身顶满；换页器遗留 `align-self: end; margin-bottom: -2px` 再向下压，底部行整体骑在圆角边框上。
3. **超期无预警**：顶行对超期与否零视觉差异（`已结转` 仅覆盖无截止时间的待办）；到期提醒是独立功能，未设提醒的事项不会有任何提示。

## 提案（v5，经多轮确认；完成流程改为二次确认）

- **两层结构**：正面卡改为「主区（确认方块 + 标题）+ 底部 meta 行（标签 … 换页器）」；meta 行收进内边距，换页器去掉负 margin。标题列拿回约 60px，常规标题恢复单行。
- **加高**：86px → 92px（背后垫片同步 +6px，底部露出约 6px 保持叠层感）；AI 建议共存的紧凑变体 66px → 72px。
- **角落徽章**（胶囊样式对齐 AI 建议卡的「待确认」）：
  - 徽章绝对定位**卡片左上角**，时间绝对定位**右上角**（对称位），主区顶部内边距让位；
  - 三色区分（用户指定待办用绿）：`待办`＝语义绿（success-soft/success，与测试成功色同源）、`日程`＝蓝灰（#e3ecf3/#3f6b8f）、`已超期`＝红（danger-soft/danger）；超期时右上角时间同步转红加粗；
  - 未超期不显示状态徽章，仅类型徽章。
- **确认方块（方案 A）**：20px 圆形细边（#b7b0a6），悬浮描边转主色 + accent-soft 底。
- **完成＝二次确认**（用户指定，替代 2.5 秒停留撤销）：
  - ① 常态：底部行为标签 + 换页器；
  - ② 首次点击勾选框 → **待确认态**：勾选框变主色填充 + 柔光圈，meta 行换页器位置就地替换为 `[✓ 确认完成] [取消]`（数据未写入）；
  - ③ 点 [✓ 确认完成]（或再次点击勾选框、按 Enter）→ 立即落盘、卡片离开叠层显示下一项；无停留、无撤销；
  - 解除路径：点 [取消]、Esc、翻页/滚轮/切换模式（先取消再执行原操作）、4 秒无操作自动解除——全部静默回常态，无副作用；
  - 语义：防误触从事后撤销挪到事前确认，数据只在确认后落盘，无延迟提交的丢失风险；完成后反悔走主界面/事项库编辑。
- **标题换行**：沿用 `-webkit-line-clamp: 2`；截断时沿用现有 `title` 属性悬浮显示完整标题（原生工具提示；自定义气泡为可选项）。
- **换页箭头**：Phosphor CaretDown，向上者 rotate 180°，等高对齐。
- 超期判定 = 待办取截止时间、日程取发生时间，早于当前即成立。日程卡无勾选框、不参与完成流程。

## 实现要点（0.5.6）

- `mini-card.css`：`.mini-task-front` 改 flex column（`.front-main` + `.front-meta`），高度 92/72；新增 `.mini-pill`、`.check-a`（含 `.armed`）、`.confirm-bar/.confirm-btn/.confirm-cancel`；删除 `mini-undo-done`。
- `MiniCard.tsx`：移除 `DONE_HOLD_MS`/`heldDone`/`undoDone`/`completeCurrent` 的停留逻辑；新增 `armed` 状态（存 id + 4s 定时器）：首次点击 arm、再点/Esc/翻页 disarm、确认才 `api.update(status: 'done')`。
- 徽章：`remaining` 渲染处计算 `isOverdue`；顶端行改角落徽章结构，标签 `<span>` 移入 meta 行。
