# 主界面收起为卡片：待选设计

状态：2026-09-17 高保真交互预览，等待用户选型。未接入正式应用。

打开 `preview.html` 可直接离线体验。`comparison.png` 为默认对比，`conversation.png` 为对话状态，`confirmation.png` 为修改确认，`narrow.png` 为 340 px 窄宽。

## 两版共有的行为

- 主窗口宽度和上沿位置不变，下沿向上收紧；根据用户反馈，卡片高度从 340 px 收紧至 280 px。恢复时回到收起前的高度。
- 收起为卡片、隐藏主窗口、显示独立悬浮入口是三个不同操作。卡片与现有悬浮图标可以同时存在。
- 主界面顶部增加“收起为卡片”；卡片右上角提供“展开主界面”。卡片保留置顶、悬浮入口开关。
- 新增、勾选完成、AI 提问、预览修改并确认，在卡片中完成。长列表、长回复在内容区滚动，输入或确认操作固定在底部。
- 常用任务编辑可在卡片内暂时替换正文，保存后回到列表；事项库、完整设置通过展开进入。本轮预览展示核心待办和 AI 流程，不展示完整编辑器。
- AI 会话和草稿应在卡片与现有独立 AI 窗口之间延续。具体双窗口同步机制留到选型后实施；不创建第二份独立历史。

## A：同卡切换

默认是待办列表，顶部“今日待办 / AI 助手”切换正文。AI 模式顶部保留下一条未完成待办和剩余数量。优点是空间充足、对话和修改详情更易阅读；代价是查看完整任务列表需要切回。

## B：同时显示

上半部保留待办列表，下半部显示 AI。列表默认露出两条，两个区域各自滚动。确认操作时 AI 区优先显示任务标题、修改前后和操作按钮，不重复展示整段问答。优点是随时对照任务；代价是长对话滚动更频繁。
