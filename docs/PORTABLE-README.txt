To Do List Windows 免安装版

使用方法
1. 请先完整解压 ZIP，不要直接在压缩包预览窗口中运行。
2. 双击“To Do List.exe”启动。
3. 请保留同目录下的 resources、locales、DLL 和其他文件，不能只复制 exe。
4. 关闭主窗口只隐藏主界面，悬浮入口和 AI 对话继续保留；需要彻底退出时，请右键托盘图标并选择“退出（停止提醒）”。
5. 点击主窗口底部的星形按钮可打开独立 AI 悬浮窗；主清单不会被替换，AI 窗口可拖动和缩放。

升级方法
1. 先从托盘彻底退出旧版本。
2. 解压新版，替换整个旧程序目录，或放到新的文件夹中运行。
3. 事项和标签保存在 %APPDATA%\To-Do-List，更换程序目录不会清空数据。
4. 升级前建议在“设置 → 本地数据”中导出一次备份。

系统要求与提示
- 当前版本面向 Windows 11 x64；尚未完成 Windows 10、ARM64 兼容认证。
- 用户不需要单独安装 Node.js、Python 或 SQLite。
- 当前程序未购买代码签名证书，Windows 可能显示“未知发布者”。
- 应用完全退出、电脑关机或休眠期间无法发送提醒；再次启动或唤醒后会补查。
